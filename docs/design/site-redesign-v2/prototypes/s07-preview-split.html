这是一个纯前端的文件工作台：浏览器直连你自己的 S3 桶或 WebDAV 服务器，凭证只保存在你的浏览器里，不经过任何业务后端。

  • 浏览、上传、分享，全程本地完成
  • 大文件自动分段，断点续传——关掉浏览器再打开，从上次的进度继续
  • 四种具名预设一键分享：只读 / 可编辑 / 投递箱 / 隐藏下载

上传走分块写入，核心只是一句 putObject；每一段传完即落桶，所以进度可以随时保存。
