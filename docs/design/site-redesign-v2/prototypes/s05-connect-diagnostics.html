连不上 http://localhost:9000 已定位：跨域（CORS）未放行

浏览器在「安全预检」被挡住。到存储的控制台（或网关）补齐四项：

AllowedOrigins 加 http://localhost:5200 ——演示站就跑在这个地址
AllowedMethods 放行 GET · PUT · POST · DELETE · HEAD
AllowedHeaders 设为 *
ExposeHeaders 加 ETag ——缺这条，大文件上传必败
网关侧等效配置示例（nginx） 
location / {
    add_header Access-Control-Allow-Origin  "http://localhost:5200";
    add_header Access-Control-Allow-Methods "GET, PUT, POST, DELETE, HEAD";
    add_header Access-Control-Allow-Headers  "*";
    add_header Access-Control-Expose-Headers "ETag";
}

检查访问密钥 ID 与访问密钥是否成对；密钥仅显示一次，丢了就到控制台重新签发。
也可能是「服务器没开或地址打错」
演示服务没起？跑 pnpm dev:webdav（端口 5240），再核对地址里的协议与端口。
