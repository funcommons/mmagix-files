第 1 步 · 选存储类型

你要连到哪里？二选一——选完只出现该类型需要的字段。

S3 对象存储

连到哪里——

AWS / 阿里云 OSS / MinIO / Cloudflare R2

对照：backend.type = "s3"

WebDAV 服务器

连到哪里——

Synology NAS / 坚果云 / alist 网关

对照：backend.type = "webdav"

第 2 步 · 填最小必需项——S3 只需 3 项（展开示意）

对象存储的访问入口，含端口（对照 endpoint）

桶的名字（对照 bucket）

成对申请，关掉这页就再也看不到（对照 accessKeyId / accessKeySecret）

高级选项（11 项，可不管）
区域标识 region按厂商文档填；多数 S3 兼容实现 us-east-1 或 auto 可用
文件夹（可选，默认根目录） prefix只看这个前缀下的内容
会话密钥（可留空） sessionToken临时凭证；本地密钥模式不需要
挂载路径 mountPath=你将看到的名字；默认取存储空间名
大文件自动分段、断点续传 chunkedWrite默认开
缓存有效期 ttl列表多久自动刷新；默认 3600 秒
界面外观 appearance浅色 / 深色 / 跟随系统
界面语言 language中文 / English
目录树形态 treeMode侧边栏 / 抽屉
Markdown 打开方式 mdMode自动 / 源码 / 双栏 / 预览
插件 plugins6 个官方插件按需启用

其余 11 项全部收进这里——必填的只有上面 3 项。

第 3 步 · 连接
点一下「测试连接」。连不上不是一句红字——会给出三类原因的分诊与修复步骤（见下一屏诊断）。
第 4 步 · 进入文件浏览
连接成功直接落在文件管理器：网格浏览、拖拽上传、右侧详情（见文件浏览屏）。
下一步会只出现 S3 需要的字段；换选 WebDAV 则改问用户名和密码。
