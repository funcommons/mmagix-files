## 三、差异化结论（独有且守得住的）

1. **零后端 S3 直连 + 可嵌入**——九家中唯一「一个桶+预签名就能跑、还能长在别人应用里」的形态；嵌入 SDK+参数通道是护城河
2. **纯前端办公全家桶**（Univer 编辑/ExcelJS 样式/PDF 签批压平/HTML 单体化）——Nextcloud/Cloudreve 的 Office 编辑都要挂 OnlyOffice 容器
3. **安全网三件套纯前端闭环**：回收站（能力探测门控）/版本历史（copy-source 恢复）/信封分享——copyparty/alist/filebrowser 全没有
4. 工程纪律（1828 例+覆盖��门禁+E2E 证据链）——对照 MinIO「只给源码不给二进制」的信任崩塌，纪律本身就是卖点

## 四、升级建议（下一波，按纯前端边界内可行性排序）

### P0（补可见硬缺口）

1. **目录（前缀）分享**：四/五家都有而我们是 ✗——预签名 List + 既有信封加密复用即可做「目录浏览型分享页」（只读列表+逐文件下载），密码/过期全继承。~2-3 天
2. **搜索内容级**：文本类文件预览/上传时顺带索引正文进 IDB（copyparty 的「按内容找相似」= hash/相似度纯前端可做），搜索结果命中片段高亮。~2 天
3. **缩略图持久化 + 网格视图**：图片上传/浏览时 canvas 生成缩略图存 MetaStore，列表加网格模式——copyparty 的缩略图索引与 Nextcloud 网格视图是流量最大的 UI 形态。~2 天

### P1（体验加固）

4. **传输中心二期**：整批聚合进度条+实时速度/剩余时间（EventTarget 节流已备）+「重试全部失败」
5. **桶仪表**：对象计数/容量/Top 前缀统计（ListObjectsV2 遍历+IDB 缓存），补 MinIO Console 被砍掉的管理面
6. **音频播放增强**：频谱图/均衡器（copyparty 招牌之一，Artplayer 体系内可容）
7. **能力门控扩展**：把回收站的探测模式复制到「多版本桶优化体验/解压缓存」等能力面，无能力时隐藏而非报错（本次订单验证过的 UX 范式）

### P2（远期/择机）

8. **Univer 多人协同**：yjs+WebSocket 中继（纯前端兼容的协作路线，对标 WOPI 但不破红线）
9. **单组件 vendoring 导出**（TreePanel/PreviewTabs 独立 npm 包）
10. **i18n 扩语种**（借宿主分发场景按需挂载词典）

### 明确不做（破纯前端红线，竞品有但放弃）

离线下载/磁力（服务端拉取）· WebDAV 服务端 · 用户体系/配额运营（宿主自有）· 视频转码（copyparty 服务端转码是服务端红利，不追）

> **一句话总结**：TOP5 里两颗巨星已死、一颗信任裂痕；活着的的三家没有一家能「纯前端直连 S3 + 嵌入」。功能面我们的独有区（办公全家桶/安全网三件套/嵌入插件）全部守住，硬缺口只剩**目录分享**一个 P0——它做完，分享面对齐 Cloudreve/copyparty 且密码强度反超。
